# Contributing

1. Create an issue describing the change and acceptance test.
2. Branch from the latest `main`.
3. Keep kernel changes focused and document lock/ownership rules.
4. Add a focused test and run `usertests -q`.
5. Save raw evidence under `reports/<feature>/raw/`.
6. Open a pull request using the repository template.

Do not submit generated xv6 build files, disk images, or unrelated formatting.
